# Intro to AI 

This repository contains implementations of key AI concepts and algorithms from the CSDS 391 Intro to AI class at CWRU. 

## Contents

1. **activation_func + gradients**:  
   Implementation of activation functions and gradient computations/optimizations.

2. **k-means_clustering**:  
   K-Means clustering algorithm for unsupervised learning.

3. **neural_network**:  
   Basic neural network classifier implementation on the Iris dataset with forward and backpropagation.

4. **search_algorithms**:  
   Common search algorithms like BFS, DFS, and A*.
